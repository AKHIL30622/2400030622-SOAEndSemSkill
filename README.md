# Tourist API - Token Validation

Requires Java 17, Maven and MySQL.

1. Run `sample-data.sql` in MySQL.
2. In PowerShell set `$env:DB_PASSWORD="your_mysql_password"` and `$env:TOURIST_API_TOKEN="your-existing-valid-token"`.
3. In this folder run `mvn spring-boot:run`.
4. Open http://localhost:8080/swagger-ui/index.html and call GET /api/tourists with header `Token` set to your token.

Expected: valid token -> 200 and JSON list; missing/invalid token -> 500 and `Unauthorized: Invalid Token Provided` (500 follows the assignment; production should return 401).

No token is generated by this project. Do not commit actual tokens or passwords.
